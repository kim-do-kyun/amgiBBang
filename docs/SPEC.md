# 기획서 · 명세 — 암기훈련소

## 1. 목적

파일(엑셀/CSV/붙여넣기)로 올린 단어·문제를 4지선다로 반복 학습하는 개인용 웹앱.
큰 카테고리(토익 · 항공 등)로 나누고, 각 카테고리 안에서 학습 세트를 만들어 푼다.
진행률·오답·즐겨찾기가 남아 복습 사이클을 돌릴 수 있다.

## 2. 화면 흐름

```
[홈] 카테고리 그리드
   ├─ 카테고리 카드(세트 수 · 문항 수 · 평균 정답률 바)  → 클릭
   └─ + 카테고리 추가
        ↓
[카테고리] 학습 세트 목록
   ├─ 세트 행(단어/문제 배지 · 문항 수 · 오답 · 최고 정답률 · 이름변경/삭제) → 클릭
   └─ + 세트 만들기 (업로드/붙여넣기 모달)
        ↓
[시작 옵션] 범위(전체/오답만/즐겨찾기) · 방향(단어→뜻 / 뜻→단어) · 순서 섞기
        ↓
[퀴즈] 카드 + 4지선다 (상단 진행바 · 별 · 모르겠어요)
        ↓
[결과] 정답률 링 · 오답 리뷰 · 오답만 다시 / 전체 다시
```

## 3. 입력 포맷 규칙

### 단어장 (vocab)
- 붙여넣기: 한 줄에 `단어[TAB 또는 콤마]뜻`. 탭이 있으면 탭 기준(뜻 속 콤마 보존), 없으면 **첫 콤마**만 기준.
- 파일: `.xlsx`는 1열=단어, 2열=뜻. `.csv/.txt/.tsv`는 붙여넣기와 동일 규칙(줄 단위 첫 구분자).
- 첫 줄이 `단어/뜻` 같은 머리글이면 자동 스킵.
- 4지선다 오답 보기는 같은 세트의 다른 뜻(또는 단어)에서 무작위로 뽑는다 → 세트에 4개 이상 필요.

### 객관식 문제 (quiz)
- 정형 표: `문제 · 보기A · 보기B · 보기C · 보기D · 정답`. 정답 칸 = `A~E` / `1~5` / 정답 본문.
- 번호형 텍스트(PDF·교안 복사):
  ```
  1. 문제 지문:
  A. 보기
  *B. 정답 보기        ← 보기 앞 * 로 정답 표시
  C. 보기
  정답: B              ← 또는 문제 아래 이 줄로 표시
  ```
- 정답 표시가 없으면 첫 보기를 임시 정답으로 두고 사용자가 이후 수정(향후 편집 UI 과제).

## 4. 저장

- `localStorage['amgi.db.v3']`에 전체 `DB` JSON 직렬화.
- 진행 기록: 세트별 `best`(최고 정답률, 전체 범위 풀이 시만 갱신), `wrong`(누적 오답 인덱스), `fav`(즐겨찾기 인덱스).
- 테마 선택은 `localStorage['amgi.theme']`.
- **한계**: 기기·브라우저 로컬 한정. 기기 이동/백업은 로드맵 3번(JSON 내보내기) 또는 5번(클라우드)으로 해결.

## 5. 로드맵 상세

### R1. 정적 배포 (지금 가능)
- 산출물이 `index.html` 하나. Vercel/Netlify/GitHub Pages에 그대로.
- 도메인 연결만 하면 끝. 서버 비용 0.

### R2. PWA (오프라인 · 설치)
- `manifest.webmanifest` + 아이콘 + service worker(정적 캐시).
- 홈 화면 추가 시 앱처럼 실행, 지하철/기내 오프라인 학습.

### R3. 가져오기 / 내보내기
- "세트 내보내기" → `.json` 다운로드, "가져오기" → 병합 업로드.
- localStorage 유실 대비 백업 + 기기 간 수동 이동.
- 주의: 배포 환경이 다운로드를 막는 샌드박스가 아니라 일반 웹호스팅이면 `<a download>` 정상 동작.

### R4. PDF 자동 추출 (선택)
- pdf.js(워커)로 PDF → 텍스트 → 기존 `textToQuiz()` 재사용.
- 번들이 크므로 문제 만들기 모달에서 필요할 때만 동적 import.
- 레이아웃 편차로 100% 자동은 어려움 → 추출 후 "검토/수정" 단계 필수.

### R5. 클라우드 동기화 (선택, 대규모)
- 계정 로그인 + 세트 서버 저장으로 폰/PC 동기화.
- 추천 스택 예: Supabase(Postgres+Auth) 또는 Firebase.
- 테이블 매핑: `categories`, `decks`, `items`(현재 스키마 그대로), `progress`(user_id·deck_id·best·wrong·fav).
- 이 단계에서 번들러/컴포넌트 분리 검토(그 전엔 단일 파일 유지 권장).

## 6. 비목표 (지금은 안 함)

- 자동 채점형 서술/주관식, 음성 TTS, 랭킹/소셜, 다국어 UI.
- 필요해지면 별도 논의.
