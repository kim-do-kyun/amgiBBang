The Stack

레이어별로 뜯어보기

직접 구현 표시는 라이브러리 없이 손으로 짠 부분 — 포폴에서 강조하기 좋은 대목이다.

Vanilla JS프론트엔드

무의존

React·Vue 같은 프레임워크, Webpack 같은 번들러 없이 순수 웹 표준으로.

어떻게 — 상태 객체 DB + route 를 두고 render()로 화면을 다시 그리는 자체 라우팅. 테마는 CSS 변수로 라이트/다크 전환.

SupabaseDB · 인증 (BaaS)

managed

서버를 직접 만들지 않고, 관리형 Postgres + 인증을 브라우저에서 바로 호출.

어떻게 — 테이블 categories·decks·items. Row Level Security로 로그인한 사용자 본인 데이터만 접근. 그래서 공개 키를 프론트에 둬도 안전.

동기화 계층pull / push

직접 구현

로그인하면 폰·패드·PC가 같은 데이터를 보게 만드는 핵심.

어떻게 — 로그인 시 서버에서 pull → 변경마다 디바운스 mirror push(전체 upsert + 사라진 행 삭제). localStorage는 오프라인 캐시로 유지.

Auth매직링크 · 비밀번호

Supabase Auth

비밀번호 없이 이메일 링크로 로그인, 원하면 비밀번호도.

어떻게 — 이메일 매직링크(implicit flow — 모바일 호환) 기본, 계정에 비밀번호 설정 시 어느 기기서든 즉시 로그인. 미로그인은 게이트로 앱 진입 차단.

XLSX 리더엑셀 파싱

직접 구현

SheetJS 같은 외부 엑셀 라이브러리 없이 브라우저 API만으로.

어떻게 — .xlsx는 사실 ZIP. 중앙 디렉터리를 직접 읽고 DecompressionStream으로 압축 해제 → 내부 XML 파싱. 셀·한글·콤마까지 처리.

pdf.jsPDF 텍스트 추출

v4.10.38

PDF 문제집에서 글자를 뽑아 4지선다 문제로.

어떻게 — 필요할 때만 esm.sh에서 동적 로드(워커 포함) → 텍스트 추출 → 번호형 문제 파서에 연결. 정답 없는 PDF는 정답 편집기로 지정.

tesseract.js이미지 OCR

v5

단어 스크린샷(캡쳐)을 글자로 인식.

어떻게 — 이미지 업로드 시 동적 로드해 한글+영어 인식 → 파싱. 진행률 표시. 처음 한 번만 언어데이터 다운로드.

텍스트·CSV 파서붙여넣기 입력

직접 구현

엑셀 복사·CSV·번호형 문제 텍스트를 알아서 인식.

어떻게 — 따옴표 CSV, 뜻 속 콤마 보존, 1./A./*정답 번호형 문제, 단어장↔문제 형식 자동 감지까지 규칙 기반으로.

Why

핵심 설계 결정 3가지

"왜 그렇게 만들었어요?" 라고 물으면 이렇게 답하면 된다.

Q. 왜 프레임워크·빌드가 없어?

단일 파일 · 무빌드

규모가 작아 프레임워크 오버헤드가 이득보다 크다. 파일 하나라 어디든 바로 올라가고, 열면 곧바로 실행된다. 가볍고 배포가 쉽다.

Q. 무거운 라이브러리는?

CDN 동적 import

supabase·pdf.js·tesseract는 첫 로딩을 무겁게 하지 않도록 실제로 쓰는 순간에만 불러온다. 초기 진입은 가볍게 유지하면서 기능은 다 챙긴다.

Q. 서버는 왜 없어?

서버리스 + RLS

인증·DB를 Supabase에 맡겨 운영할 서버가 없다. 보안은 Row Level Security가 DB 단에서 "내 데이터만"을 강제 → 공개 키 노출도 안전.

이력서 · 면접용 한 줄

  • 프레임워크·빌드 없이 순수 웹 표준(Vanilla JS)으로 만든 단일 파일 학습 웹앱 — Supabase 백엔드 + Vercel 정적 배포.
  • 이메일 매직링크·비밀번호 인증과 크로스 기기 동기화(pull/push + 오프라인 캐시)를 직접 구현.
  • 외부 라이브러리 없이 브라우저 API(DecompressionStream)로 XLSX 파서를 구현, PDF·이미지(OCR)까지 업로드 파이프라인 구축.
  • PWA로 홈 화면 설치·오프라인 지원, RLS 기반 데이터 보안 설계.
